# ÍRIS Evidence Base

This repository contains the structured evidence base used in the development of the ÍRIS taxonomy for the evaluation of Large Language Model (LLM) outputs.

## Contents

- `data/iris_evidence_base.xlsx`: consolidated evidence extracted and standardized from the selected primary studies.
- `docs/data_dictionary.md`: description of the variables and categories used in the evidence base.

## Scope

The dataset contains evidence extracted from 47 primary studies published between 2023 and April 2026, covering domains, tasks, quality aspects, evaluation objectives, automation levels, risks, metrics/methods, and standardized evaluation families.

## Research context

The evidence base supports the development of the ÍRIS taxonomy, a multidimensional taxonomy intended to assist researchers in selecting evaluation strategies for LLM outputs according to the characteristics of different evaluation scenarios.
